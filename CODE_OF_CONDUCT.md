# Code of Conduct

## Our commitment

AnalysisXMD is a project for the scientific and open-source community. We are committed to providing a friendly, welcoming, and respectful environment for everyone who participates — regardless of background, experience level, nationality, or field of study.

## Expected behavior

Everyone interacting in the project (issues, pull requests, discussions, email) is expected to:

- Be respectful, professional, and considerate.
- Give and accept constructive feedback gracefully.
- Focus on what is best for the project and the community.
- Assume good intentions and collaborate in good faith.

## Unacceptable behavior

Disrespectful, harassing, or disruptive behavior toward other participants is not acceptable. This includes personal attacks, insults, or any conduct that makes others feel unwelcome.

## Scope

This Code of Conduct applies to all project spaces — the repository, issues, pull requests, discussions — and to any public or private communication related to the project.

## Reporting

If you experience or witness behavior that violates this Code of Conduct, please contact the maintainer directly. All reports will be handled confidentially and reviewed in good faith.
